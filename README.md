# 🎓 SkillCraft

An AI-assisted web application that helps students identify skills from their projects and assignments, then draft the project section of a CV.

## 📖 Overview

SkillCraft supports IT and non-IT students through a simple three-field form: Project title, Project overview and What you did.

Students can describe their work in simple English, list tools they used or paste an extract from their own report. They review the suggested skills before generating their CV project section.

## ✨ Features

- Simple project and assignment input
- One student survey sample to try the workflow
- Up to six AI-suggested skills
- Editable CV project section
- Responsive interface for desktop and mobile
- Trial access code for invited online testing

## 🛠️ Built With

- Next.js
- React
- JavaScript
- CSS
- Node.js
- Google Gemini API

## 📌 Notes

- Skill suggestions and CV wording should be reviewed by the student.
- The application currently supports English input and output.
- Work stays in the current page and is cleared by a refresh; export before leaving.
- Project details are sent to Google's Gemini API for generation.
- API availability depends on the configured project's quota.
